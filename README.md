# GuessingApp
## Use Case 3: Hint Generation

**Description:**
- Generate hints after inccorect guesses
- Limit number of hints
- Provide meaningful hints
- Increase difficulty gradually
- Ensure hints don't reveal exact number

**Classes Involved:**
- `HintService.java` - Responsible for generating controlled hints based on the number of inccorect attempts made by the player
- `GuessingApp.java` - Coordinates the game flow: Initialize game, Accept user guesses, Validate the guess, provide hints and stop when the game ends

**Key Concepts:**
- Modulus and arithmetic operators
- Method abstraction
- Encapsulation of hint logic
