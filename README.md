# GuessingApp
## Use Case 1: Game initialization

**Description:**
- Generating a random target number within a predefined range
- Initialize maximum attempts
- Initialize hint counter
- Store game configuration
- Display game welcome message and rules

**Classes Involved:**
- `GameConfig.java` - Responsible for setting game boundaries, generating a random target number and diaplaying game rules
- `GuessingApp.java` - The main entry point of the program, Initializes game config and displays game rules

**Key Concepts:**
- Constructor Initialization
- Encapsulation
