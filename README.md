# GuessingApp
## Use Case 2: User Guess Submission

**Description:**
- Accept user input
- Validate numeric input
- Compare guessed number with target
- Track number of attempts
- Provide feedback(higher/lower)

**Classes Involved:**
- `GameValidator.java` - Responsible for Comparing the user's guess with target number
- `GuessingApp.java` - Coordinates the game flow: Initialize game, Accept user guesses, Validate guesses and stop when the game ends

**Key Concepts:**
- Method invocations
- Input Validation
