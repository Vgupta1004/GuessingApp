# GuessingApp
## Use Case 5: Game Result Storage

**Description:**
- Store game results
- Save data in file or database
- Retrieve past game records
- Display previous scores
- Maintain data integrity

**Classes Involved:**
- `StorageService.java` - Responsible for persisting the final game result after the game ends
- `GuessingApp.java` - Coordinates the complete game flow and persists the final result after completion

**Key Concepts:**
- File I/O(BufferedWriter/BifferedReader)
- Object Persistence
